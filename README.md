# Emil Alizada · Personal Portfolio

Static website for cybersecurity, DevOps, Kubernetes security, and secure backend engineering projects.

**Website:** https://emilalizada.github.io/ (published with GitHub Pages)

## Local preview

Open `index.html` directly, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Deployment

This repository is intended to be named `EmilAlizada.github.io`. Under **Settings → Pages**, choose **Deploy from a branch → main → /(root)** and save. The repository contains `.nojekyll` so the files are served without Jekyll processing.

## Contents

- `index.html` — portfolio content
- `styles.css` — responsive layout and styles
- `script.js` — progressive interface features
- `favicon.svg` — site icon
- `robots.txt`, `sitemap.xml` — crawler discovery
- `404.html` — missing-page fallback

CI badges are loaded from the public GitHub Actions workflow status endpoints for the featured repositories.

> No private data, credentials, or unverifiable certifications should be committed to this public repository.
